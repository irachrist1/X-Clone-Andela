# X-Clone-Andela

Static Twitter/X feed clone — Andela front-end layout exercise.

## The problem

You need to practice a dense social feed layout: sidebar, timeline, icons, and responsive columns — without React yet.

## What it does

Single-page X-style UI in HTML/CSS with SVG assets and `code.js` for basic interactions.

## Install

```bash
git clone https://github.com/irachrist1/X-Clone-Andela.git && cd X-Clone-Andela
open index.html
```

## How it works

- **Feed layout clone.** Sidebar navigation + main timeline — CSS grid/flex on a recognizable reference design.
- **SVG icon set.** Assets in `assets/` — scalable icons without icon font dependencies.
- **Static exercise.** No API, no auth — pure layout and styling practice.
